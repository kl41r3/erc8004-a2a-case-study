# NeurIPS 2026 robustness layer (neurips26)

This layer contains the five non-visual robustness tables of the v1.1.1 release. It
does not modify the existing `raw/`, `annotated/`,
`manifests/`, or `croissant/` layers. No manuscript is distributed with this
release.

Generated by `scripts/publish/build_neurips26_parquet.py` in the GitHub
repository (tag `v1.1.1`) from `analysis/metrics/neurips26/*.csv`, which are
in turn regenerated deterministically by
`scripts/analyse/run_neurips26_robustness.py` (seed 20260826, 2,000 bootstrap
repetitions) from the frozen 142-record ERC-8004 and 4,181-record A2A
manifest.

## Tables

| File | Rows | Content |
|---|---|---|
| `corpus_stage_counts.parquet` | 6 | Corpus-stage reconciliation: annotation archive vs. refiltered archive vs. frozen paper manifest per case |
| `bootstrap_argument_differences.parquet` | 5 | Equal-size bootstrap A2A-minus-ERC differences in argument-type shares with 95% intervals |
| `channel_argument_distributions.parquet` | 27 | Argument-type composition by source channel |
| `temporal_argument_distributions.parquet` | 36 | Argument-type composition by calendar quarter |
| `network_tie_threshold_sensitivity.parquet` | 8 | Co-participation network summaries under varying minimum tie weight |

## Schemas

- `corpus_stage_counts`: `case` (string), `stage` (string), `records` (int64),
  `interpretation` (string).
- `bootstrap_argument_differences`: `argument_type` (string),
  `sample_per_case` (int64), `bootstrap_repetitions` (int64),
  `mean_difference_a2a_minus_erc` (float64), `ci95_low` (float64),
  `ci95_high` (float64), `probability_difference_above_zero` (float64).
- `channel_argument_distributions`: `case` (string), `channel` (string),
  `argument_type` (string), `records` (int64), `group_total` (int64),
  `share` (float64).
- `temporal_argument_distributions`: `case` (string), `quarter` (string),
  `argument_type` (string), `records` (int64), `group_total` (int64),
  `share` (float64).
- `network_tie_threshold_sensitivity`: `case` (string),
  `minimum_tie_weight` (float64), `nodes` (int64), `edges` (int64),
  `density` (float64), `giant_component_ratio` (float64),
  `degree_gini` (float64), `edge_types` (string).

## Integrity and boundaries

`CHECKSUMS.json` records the SHA-256, byte size, and row count of each Parquet
table; `release_manifest.json` records the release version, seed, bootstrap
repetitions, paper corpus, and the validity boundary statement.

All results are descriptive. Equal-size resampling addresses the
142-versus-4,181 denominator imbalance but does not balance case maturity,
platform affordances, or organizational resources. The network inputs use
platform-specific edge semantics, so tie-threshold sensitivity is not a
harmonized edge-definition test. No file in this layer is a human
gold-standard validation result.
