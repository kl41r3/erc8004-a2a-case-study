# analysis/

Derived outputs from the data pipeline. Do not edit manually — regenerate with scripts.

Organized by research round: `r1/` (baseline) and `r2/` (data expansion + robustness).

---

## r1/ — Baseline single-case comparison

ERC-8004 vs Google A2A, single annotator model (MiniMax-M2.5).

### Governance metrics

| File | Description |
|------|-------------|
| `structural_metrics.csv` | Quantitative governance comparison: proposal/consensus dates, contributor counts, PR merge rate, timeline analysis. 2 rows (1 per case). Generated by `scripts/analyse/compute_metrics.py`. |
| `core_contributors.csv` | Core contributors per case: canonical handle, display name, institution, role, argument type distribution, stance distribution, bio snippets. 71 contributors. Generated by `scripts/analyse/identify_core_contributors.py`. |
| `cross_case_overlap.csv` | Authors appearing in both ERC-8004 and A2A discussions. 1 shared actor. Generated by `scripts/analyse/identify_core_contributors.py`. |

### Network analysis

| File | Description |
|------|-------------|
| `network_nodes_erc8004.csv` | ERC-8004 network nodes (67): id, label, institution, node size. |
| `network_edges_erc8004.csv` | ERC-8004 network edges (65): source, target, interaction type (reply/mention/co_comment), weight. |
| `network_nodes_a2a.csv` | A2A full network nodes (771): all contributors. |
| `network_edges_a2a.csv` | A2A full network edges (1,230): weighted co-comment interactions. |
| `network_nodes_a2a_top50.csv` | A2A ego network: top-50 most active contributors. |
| `network_edges_a2a_top50.csv` | A2A top-50 edges: weighted co-comment interactions among top contributors. |
| `network_metrics_table.csv` | Network comparison table: node count, edge count per case. Used for paper tables. |

All network files generated by `scripts/visualise/build_network.py`.

## r2/ — Data expansion + multi-model robustness

34-ERC cluster, 3 annotator models (deepseek-v4-flash, glm-4-plus, moonshot-v1-auto),
majority-vote consensus, cross-round test-retest.

### Governance & corpus

| File | Description |
|------|-------------|
| `structural_metrics.csv` | R2 governance metrics for the expanded 34-ERC cluster vs re-annotated A2A. Generated by `scripts/analyse/compute_metrics_r2.py`. |
| `agent_erc_universe.csv` | 34-ERC cluster inventory: ERC number, title, record count, most active thread. |

### Network analysis — cross-model consensus

| File | Description |
|------|-------------|
| `network_erc_edges.csv` | Expanded ERC cluster network edges (4,955): cross-standard co-participation ties. |
| `network_erc_nodes.csv` | Expanded ERC cluster network nodes (204): all contributors across 34 ERCs. |
| `network_a2a_edges.csv` | Re-annotated A2A network edges (1,657): cross-model consensus annotations. |
| `network_a2a_nodes.csv` | Re-annotated A2A network nodes (629). |
| `network_a2a_top50_edges.csv` | A2A top-50 ego network edges (R2 consensus). |
| `network_a2a_top50_nodes.csv` | A2A top-50 ego network nodes (R2 consensus). |
| `network_metrics_table.csv` | R2 network comparison table: GCR, density, degree Gini, top-3 share. |

Generated by `scripts/analyse/build_network_r2.py` and `scripts/analyse/export_top_nodes.py`.

### Network analysis — cross-round test-retest

| File | Description |
|------|-------------|
| `network_erc_nodes_cross_round.csv` | ERC network nodes from cross-round consensus (3 models × 3 rounds). |
| `network_a2a_nodes_cross_round.csv` | A2A network nodes from cross-round consensus. |

### Inter-coder reliability

| File | Description |
|------|-------------|
| `icr_cross_round.csv` | Current cross-round ICR results. Contains pairwise Cohen's κ and three-round Fleiss' κ for each canonical model and field. |
| `kappa_4models.json` | Current 4-model reliability results for MiniMax-M2.5 plus the three canonical cross-round models. |

Generated by `scripts/analyse/compute_cross_round_icr.py` and `scripts/analyse/compute_cross_model_kappa_4models.py`. These files describe the current data release. Paper tables remain historical snapshots and may use an earlier frozen overlap.
